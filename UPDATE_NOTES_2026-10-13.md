## Publishing
The full ZIP is the site root, not a subfolder. Extract it into the GitHub Pages repository root, review the Git changes, then commit and push to the published branch. Keep the included `CNAME`, `styles.css`, JavaScript and `assets/` paths. The `Changes Only` ZIP can instead be copied onto the previously updated site baseline; it is not a replacement for the original, pre-removal website.

A ZIP upload does not always remove old files already present in a repository. When synchronising manually from the old version, remove the 18 original six-photo portfolio files listed in the previous update's `CHANGES_AND_DELETIONS.txt`, plus any old gallery references. Do not delete assets still referenced from blog articles.
